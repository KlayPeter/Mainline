## 当前版本结论

- 首版只在本机运行，不上线，不做账号和多端同步。
- 产品形态为移动端优先的 Web/PWA，后续再评估原生 App。
- 本地 Node 服务承载业务 API 和 DeepSeek 调用，SQLite 是唯一事实来源。
- 用户创建和决定任务；AI 负责理解、分类、拆解、排程、评估和提出建议。
- AI 的任何建议都必须经过用户确认，才能改变任务、目标、奖励或长期记忆。
- 首版必须形成“了解自己 → 规划 → 执行 → 结果 → 奖惩 → 复盘”的完整闭环。
- 页面追求沉浸和克制，不堆数据看板、装饰信息和无用模块。
