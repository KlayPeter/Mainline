# Story 06：章节、目标、复盘与本地记忆

## 目标

让每日任务有长期去处：用户可在多个固定领域中建立人生章节、章节目标与里程碑；再通过简短复盘把进展、阻碍和下一步保存为只存在本机的长期记忆。

## 本故事分段

1. **章节与目标**：固定领域、章节、目标、目标进度与里程碑；“目标”页展示而非仪表盘。
2. **复盘与记忆**：按日期保存进展、阻碍和下一步；可回看本地条目，AI 后续只读取经用户选择的文本。
3. **凭证基础**：预留任务/惩罚凭证的本地引用，图片只供用户回看，绝不进入 AI 请求。

## 核心规则

1. 一个用户可同时拥有多个领域的活跃章节；章节不是当天的主线任务。
2. 每个章节可有多个目标；目标自身可再由多个里程碑拆成可检查的进展。
3. 任务与长期目标的直接关联必须由用户建立或确认，AI 只能建议归属。
4. 复盘、进展与图片凭证均保存在本地 SQLite/本地文件，不上传、不自动分享。
5. 长期记忆不是对用户下结论；它是用户可删除、可修订、可选择提供给 AI 的事实笔记。

## 验收标准

1. 用户能按职业、学习、创作、健康、生活建立多个章节，并在章节内管理目标和里程碑。
2. 用户可看到目标的手动进度与清晰的目标期限；未完成不自动扣分或关闭。
3. 每日/阶段复盘可记录进展、阻碍和下一步，并在刷新后保留。
4. 图片凭证不被发送到 DeepSeek，API Key 也不进入浏览器。
5. 通过 `pnpm check` 和 `git diff --check` 后分段提交。
